# Bantu Beres Garasi Pro Jual Beli Mobil & Motor

Aplikasi web multi-tenant untuk showroom mobil dan motor. Data setiap showroom dipisahkan menggunakan Supabase RLS.

Fitur inti: autentikasi, setup showroom Mobil/Motor/Gabungan, kendaraan, biaya rekondisi, HPP, dashboard aging, customer, lead, penjualan, kas, dan laporan cetak.
